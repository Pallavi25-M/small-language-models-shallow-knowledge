# Small Language Models for Shallow Knowledge Extraction

## Project Overview

This collaborative research project investigates whether Small Language Models (SLMs) can effectively perform selected tasks in shallow knowledge extraction and knowledge graph augmentation.

The project builds upon the SHALLKNOW framework and explores the potential of smaller models as alternatives to larger language models in selected stages of the workflow.

## Research Objectives

- Evaluate the performance of small language models in shallow knowledge extraction.
- Compare small language models with a larger-model baseline.
- Investigate ensemble-based strategies for combining model outputs.
- Analyse extraction quality, reliability and computational efficiency.

## Dataset

The project initially investigates the BPDP dataset for exploratory data analysis and experimental preparation.
